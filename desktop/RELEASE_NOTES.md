**Now a true overlay.** The kandil, string lights and diya float over all your Windows apps, and you keep working normally underneath.

- **Overlay mode** (default): clicks on empty space go straight to the app underneath, and the overlay never takes keyboard focus. The kandil, diya, bulbs and resize handles stay clickable and draggable.
- A click in any app still leaves a sparkle; a double-click drops a cracker onto the taskbar (can be turned off from the tray icon).
- **Play mode** (`Ctrl+Shift+D`): every click goes to the scene.
- **Options**: right-click the kandil or diya, click the tray icon near the clock, or press `Ctrl+Shift+O`. **Hide/show** `Ctrl+Shift+H`. **Quit** `Ctrl+Shift+Q`.

No install needed for phones: https://arunkw.github.io/diwali-lantern/

**Windows:** download `DiwaliLantern-Portable-<version>.exe` (single file) or the zip. The files are built by GitHub Actions from this public source, with `SHA256SUMS.txt` and a build-provenance attestation. SmartScreen may warn because the exe is unsigned: **More info → Run anyway**.
